# پوشه فونت‌های اختصاصی شما (Custom Fonts Folder)

برای قرار دادن فونت دلخواه بدون هیچ کدنویسی:
کافیست فایل فونت خود را با نام **`custom-font.woff2`** (یا `custom-font.woff` یا `custom-font.ttf`) در همین پوشه (`/public/fonts/`) قرار دهید یا کپی کنید!
سیستم به صورت خودکار فونت قرار داده شده را شناسایی و روی کل سایت اعمال می‌کند.

## پسوندهای پشتیبانی شده:
- `custom-font.woff2` (بهترین فرمت و بالاترین سرعت)
- `custom-font.woff`
- `custom-font.ttf`
